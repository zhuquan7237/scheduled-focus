定时专注 v0.3.0 · 微信额度与专注警示

### 新功能

- 微信不在白名单且处于限制时段时，打开普通页面才开始连续 2 分钟使用；到期退回桌面并冷却 5 分钟。冷却结束不自动消耗下一轮额度。
- 普通页面显示剩余时长；额度与冷却持久保存，离开页面不暂停，重连服务不重置。重启后保守恢复 5 分钟冷却。
- 已识别的微信通话页面单独放行；通话不会赠送额外聊天时长，返回普通页面恢复对应限制。
- 默认隐藏最近任务卡片；移除 UI 任务后无障碍服务仍可独立拦截。桌面入口、运行通知和系统权限管理保留。
- 新增自定义警示标语与补充提醒，三种高对比配色、三种字体、24–44 sp 字号和 4–10 秒停留时间，支持实时预览及恢复默认。
- 内置备考、工作、戒拖延、长期目标、温和提醒、强警醒六套警示，一键套用标语和推荐样式，仍可自由修改。
- 原有每周时间表、白名单、自动检查与应用内更新保持可用；旧设置自动迁移。

### 使用

在「今日」调整标语与样式；限制期间仅能预览。「运行保障」可在空闲时调整最近任务卡片显示。微信在白名单或不在限制时段时正常使用。

下载附件 `scheduled-focus-v0.3.0.apk`。Android 8.0 及以上，沿用原签名，可覆盖升级并保留设置。

### 验证与边界

时间规则、2/5 分钟边界、持久化、通话分支、设置迁移、锁定和最近任务行为均纳入测试；完整实测结果见仓库 docs/VALIDATION.md 与 docs/V030.md。

微信来电分支通过明确标记“非微信”的模拟测试窗口验证，模拟器未登录真实微信。真实接听、锁屏来电、群通话、悬浮小窗及具体微信版本兼容性仍需真机验证，不能把模拟结果当作真实微信接听通过。

隐藏最近任务不等于隐藏进程或系统级保活，不能阻止系统强停、撤权、清数据、卸载或厂商后台清理。拦截是返回桌面，不是强停微信后台。
