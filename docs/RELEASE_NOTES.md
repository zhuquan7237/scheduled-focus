定时专注是一款以每周时间表为核心的 Android 自律工具。一次安排，到点限制，结束恢复。

### v0.2.1

- 修复共享网络出口下 GitHub REST API 额度耗尽（403）时无法检查更新的问题。优先读取发布流程自动生成的静态更新信息，保留 REST API 备用来源。
- 保留系统设置，允许管理权限、停止和卸载；严格限制只作用于应用内规则修改。
- 更新操作按钮置于说明之前，长说明默认折叠，避免安装入口被挤到页面底部。
- 标签构建先生成候选包，验证通过后再转为正式版本；预发布不参与普通用户的自动更新。

### 界面与功能

- 今日、时间表、白名单、运行保障四个页面，采用森林绿配色与统一图标。
- 支持每周重复、跨午夜、重叠相邻时段连续执行。
- 限制期间锁定时间表、白名单及总开关；必要电话、桌面、键盘等交互自动保留。
- 完整首次配置流程、编辑校验、立即限制二次确认，以及白名单搜索与筛选。
- 自动检查 GitHub 正式发布版本，应用内下载、校验包名/签名后交给系统安装。限制期间不能启动安装。
- 增加自动化检查和签名发布工作流，后续版本沿用同一签名以支持覆盖更新。

### 安装

下载附件中的 `scheduled-focus-v0.2.1.apk`，安装后按引导选择时段、白名单、开启无障碍服务与闹钟权限。小米 / Redmi 还应按运行保障提示检查自启动与后台省电设置。

Android 8.0 及以上。此版本保留最初测试包的签名身份，支持从原 v0.1.0 覆盖升级。

### 验证与边界

模拟器验证不等于 HyperOS 真机验证。真实电话、支付、厂商后台策略、多窗口等仍需目标设备实测。普通安装不能阻止系统强停、撤权或卸载；前台拦截不会停用其他应用后台进程。完整记录见 `docs/VALIDATION.md`。
