# v0.3.0：微信额度与专注警示

## 微信规则

仅在时间表已启用、当前处于限制时段、微信不在全局白名单时生效。微信在白名单或空闲时仍正常使用；其他普通应用的限制不变。

1. 准备状态不会消耗额度。首次打开微信普通页面开始连续 120 秒计时。
2. 切回桌面、打开其他应用或息屏均不暂停本轮计时；到截止时刻进入 300 秒冷却，普通页面退回桌面，不是系统级强停微信后台。
3. 冷却中再次打开不会重置截止时间。
4. 冷却结束只恢复待用资格；未打开微信时，下一轮 120 秒不开始。
5. 已识别的微信通话页面单独放行，不消耗未开始的额度，也不延长正在运行的本轮额度或冷却。回到普通页面后立即恢复对应限制。

使用单调时钟与持久化状态，修改系统时钟不会改变本轮 2 分钟 / 5 分钟长度；服务重连不重置额度。手机重启后单调时钟失效，保守恢复 5 分钟冷却，避免重启赠送新额度。系统强停、清数据、撤权、卸载等仍属于普通安装能力边界。

## 微信来电兼容范围

无障碍窗口事件识别到 `com.tencent.mm.plugin.voip.ui.VideoActivity` 或 `com.tencent.mm.plugin.voip.ui.VoipVoiceActivity` 时视为通话页面。只使用包名和窗口类名，不读取消息、联系人、聊天文字或通知内容。

微信没有向本应用提供稳定的通话状态公共接口。窗口类名可能随微信版本变化；服务在通话中重连、悬浮小窗、群通话和特殊机型可能无法正确识别。不能宣称所有微信版本的来电都已验证。真实接听、锁屏来电、通话结束回聊天、多窗口仍需目标手机实测。

仓库提供 opt-in 的 `wechat-fixture` 测试模块，其包名和窗口类名用于验证拦截分支，界面明确写着“非微信”，不具备聊天、登录、网络或真实通话能力，带 testOnly 标记且禁用 release 变体；不会加入正式安装包，也不能替代真实微信验证。只允许在没有真实微信的模拟器上安装，不能覆盖用户微信。

## 自定义警示

入口：「今日 → 自定义标语与警示样式」。可以调整主标语（60 字）、补充提醒（140 字，可留空）、黑金 / 警戒红 / 森林绿三种配色、力量黑体 / 衬线 / 等宽字体、24–44 sp 字号和 4–10 秒停留时间，支持实时预览和恢复默认。

内置「备考、工作、戒拖延、长期目标、温和提醒、强警醒」六套预设，点击即可同时套用标语、补充提醒和推荐样式，无需自己构思。套用后仍可自由修改，保存前不会改变当前警示。

限制期间只能预览，不能保存更改。拦截后显示高对比居中卡片，不接管触摸；锁屏和已识别通话页面会移除，避免妨碍必要操作。系统字体缩放和中文字体回退会影响实际观感。

## 最近任务

默认隐藏本应用在最近任务中的卡片；在「运行保障」中可于空闲时调整。不隐藏桌面图标、运行通知或系统管理入口。无障碍服务由系统独立绑定，不依赖主页面任务存活；移除本应用 UI 任务后应继续拦截。

这不是进程隐藏或系统级保活。小米 / Redmi 的后台清理、省电设置仍可能终止服务，需要检查自启动、无限制和权限。无法保证堵住系统强停、撤权、清数据或卸载。

## 复现测试

```powershell
# 显式构建测试夹具；不要在装有真实微信的设备上安装
.\gradlew.bat :wechat-fixture:assembleDebug '-PwechatFixture=true'
# 安装后运行默认集成测试；夹具不存在时相关用例跳过
.\gradlew.bat :app:connectedDebugAndroidTest
# 真实等待完整 120 秒 + 300 秒的循环，用时约 7 分钟
.\gradlew.bat :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.zhuquan.scheduledfocus.RuntimeIntegrationTest#fullWeChatTwoPlusFiveMinuteCycle' '-Pandroid.testInstrumentationRunnerArguments.fullWeChatCycle=true'
```

Windows 中文路径环境建议按 README 设置英文 `FOCUS_BUILD_ROOT`。普通测试覆盖完整规则边界、重连持久化、通话与聊天切换、冷却结束仍不自动计时、旧设置迁移、自定义样式保存及锁定、最近任务标志与移除 UI 任务后的拦截。
