# 验证记录与 HyperOS 真机验收

交付版本：0.2.1；验证日期：2026-10-30。

## 环境与范围

- Windows、JDK 17、Android SDK / Build Tools 35。
- AVD 名称为 XiaomiTurbo3QA，但运行的是 Google Android 17 / API 37.1、x86_64、16 KB 页模拟器。**名称不代表小米硬件或 HyperOS。**
- 未连接 HyperOS 真机，以下模拟器结论不能代替目标手机验收。

## 自动验证

- 25 项 JVM 测试：23 项覆盖示例三个时段与起止边界、星期、周末跨午夜、重叠相邻合并、整周连续、今日列表、时区、夏令时、时间跳变、保存锁定和立即生效确认；2 项验证更新版本比较和异常标签拒绝。
- 5 项 Android 集成测试通过，另有 1 项真实网络测试默认跳过：覆盖本机设置往返保存、锁定时拒绝写入、已生效时段拦截、首次设置界面与返回导航，以及跨越实际开始/结束边界的完整行为。完整行为验证独立普通测试应用到点退回桌面、再次打开被拦截、白名单时钟和本应用保持可用、系统设置保持可用、结束后普通应用恢复、撤回服务后未就绪。运行命令见 README。
- Android 的设置包注册了低优先级 FallbackHome，未将其识别为可用启动器；系统设置作为权限管理所需交互显式保留。
- release 构建和 lint 通过（0 错误）；安装启动成功。人工检查 360 dp 小屏 / 130% 字体的时间表和编辑框，确认内容可滚动，保存、取消及星期选择可操作。截图位于 `screenshots/v0.2/`。
- 最终 APK 的 v2 签名、包名、四种 ABI 和 ZIP 16 KB 对齐检查通过；内置 `libandroidx.graphics.path.so` 四种 ABI 的 LOAD 段对齐均为 `0x4000`。当前为个人测试用 debug 证书签名。
- 发布附件的 SHA256 以同一 Release 中的 `SHA256SUMS.txt` 为准（本地与 CI 构建的 ZIP 元数据可能不同）。v0.1.0 历史包 SHA256：`ad52eb61ccf80e191c43757057276d4c858a381bf665594d9d2f1e1e9271aa4b`。
- 保存报告：`unit-results.xml`、`emulator-results.xml`、`lint-results.html`；实际截图在 `screenshots/`，模拟器日期和时区独立于本机，截图显示的是模拟器本地时间。

## 更新实测

GitHub 自动检查和签名发布工作流已成功执行。使用低版本号的模拟器专用测试包（0.1.99 / versionCode 1），从真实公开 Release 查询版本，通过 Android DownloadManager 下载安装包，并通过大小、SHA256、包名、签名和递增版本号校验。故意设置错误摘要时校验被拒绝，恢复正确摘要后通过。

首次实测发现共享出口的 GitHub REST API 返回 403 rate limit exceeded，已在 0.2.1 改为优先读取静态发布元数据。静态来源下的真实下载与完整性测试通过，未依赖桌面代理代下文件。

v0.2.0 的系统安装确认能正常打开，但 Google Play Protect 联网扫描返回 `POTENTIALLY_UNWANTED / generic_malware` 并拦截，安装尚未通过。不能将这个结果称为误报或安装成功。该版本已降为预发布；后续候选包在安装验证通过前不提升为正式版。

已修正限制时拦截整个系统设置的行为：系统权限管理和撤权入口必须保持可用，严格只限制本应用内规则。测试改用独立的普通应用包验证拦截，并新增对系统设置保持可用的断言。此调整不能保证改变扫描结果，需要对新候选包重新实测。

可选真实网络测试默认跳过，需使用低于最新发布版的 fixture 版本显式开启 `liveUpdates=true`。该测试会联网并下载 APK，仅在模拟器运行。普通设备测试仍以 HyperOS 清单为准。

构建脚本会执行 JVM 测试、lint 和 release 构建，附带 `-EmulatorTests` 时执行设备集成测试。报告默认保存在 `FOCUS_BUILD_ROOT/app` 的 `reports` 与 `outputs/androidTest-results` 内。

## 已知能力边界

普通安装不能阻止系统强停、撤权、卸载、清除数据或修改时间。拦截只作用于前台应用使用，不停用后台进程。必要系统包按包名保留，无法细分包内每个页面；白名单浏览器中的网页也不单独限制。

尚未完成 HyperOS、其他厂商系统、多窗口/画中画、工作资料/应用分身及真实电话/支付流程的可靠性验证。无障碍服务的连接状态和精确定时权限满足，只代表基础条件就绪。
